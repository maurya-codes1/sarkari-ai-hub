1. Project Overview & Architecture

BharatExams Hub is an all-in-one, high-performance Indian government exam and state board utility portal designed for students and job aspirants across Bharat.

  • Backend: Node.js + Express (server.js) running on port 5000 with autonomous background sync (services/auto-sync.js, services/smart-fetcher.js).
  • Frontend: Client-Side Single Page Application (SPA) with hash routing (#home, #exam/:id, #tool/:id, #mock-tests, #results, etc.). Zero webpack/vite build steps for instant loading on 2G/3G/4G networks across rural India.
  • Client Architecture:
    • public/js/app.js: Main application controller, UI event handling, 14-language universal confirmation modal, outbound link gateway.
    • public/js/router.js: Dynamic client-side router with route history and quiz abandonment guards.
    • public/js/exams-data.js: Centralized registry of 100+ exams, official links, syllabus, eligibility, and question banks.
    • public/js/quiz.js: Live CBT mock test engine with timer, question palette, sweet Indian female voice TTS, review flags, and bilingual formatting.
    • public/js/i18n.js: Complete multilingual translation dictionary for 14 Indian languages.
    • public/js/tools.js: 20-50 KB photo resizer, 7th CPC salary calculator, age eligibility calculator, typing test, CGPA converter.
    • public/js/omr.js: Vector-based printable OMR sheet generator with instant PDF download.

2. Key Problem Resolutions & Recent Fixes

✅ 1. Double-Tab Navigation Bug Fixed

Problem: When users tapped "Apply Online", an outbound gateway opened in a new tab, but simultaneously Tab 1 (BharatExams Hub) was redirected to the external government website (e.g. cbse.gov.in), destroying the user's active session and back-navigation stack.

Solution: In public/js/app.js, the fallback window.location.href = target; was completely removed. Outbound links are strictly opened in a new window via window.open(target, '_blank', 'noopener,noreferrer'). Tab 1 remains permanently intact on BharatExams Hub.

✅ 2. Comprehensive Link Audit (280 Links Audited, 37 Dead URLs Fixed)

Audit Scope: 280 link occurrences across 94 unique URLs in exams-data.js.

  • 0 Dummy Links: All #, example.com, and placeholder URLs were eliminated.
  • 37 Broken/404 URLs Replaced: Dead government domains (e.g. results.cbse.nic.in, mahresult.nic.in, rajresults.nic.in, cuetug.ntaonline.in, rrbapply.gov.in) and 404 paths (e.g. CBSE cbsenew/examination.html, UPMSP Results.html) were replaced with active official portals.

✅ 3. State Board & Exam Question Pattern Compliance (BSEB, CBSE, UP Board, etc.)

Rule Enforced:

  • Language Subjects (Matribhasha): Hindi, English, Sanskrit, Urdu, etc. questions and options are displayed in their authentic single language.
  • Non-Language Subjects: Science (Physics, Chemistry, Biology), Mathematics, Social Science (History, Civics, Geography), and General Studies questions and all four options are strictly displayed in Bilingual format: [Hindi] / [English] matching actual BSEB & State Board question papers.
  • Zero Duplicate Questions: Every question in the mock test bank is distinct.

✅ 4. Universal 14-Language Modal System

Universal bilingual modal for all alerts, test exit confirmations, and bookmark removals across 14 languages. The active language is shown first, with the secondary language (English for regional languages, Hindi for English) shown in parentheses (...).
